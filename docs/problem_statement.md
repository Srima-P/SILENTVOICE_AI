# Problem Statement

Developers often spend significant time understanding unfamiliar codebases.

When joining a new project, developers must manually inspect files, trace dependencies, understand architecture, and navigate large repositories before they can contribute effectively.

This leads to:

- Slow onboarding
- Increased debugging time
- Reduced productivity
- Knowledge transfer challenges

Existing AI coding assistants focus primarily on code generation rather than helping developers understand an entire repository.

A smarter repository understanding assistant is needed to help developers quickly explore, understand, and interact with complex projects.
